# 報告の型

AI からの報告は毎回この形にする。持ち主が30秒で判断できることが目的。
`報告/` フォルダに `報告_日付.md` として書く（`報告/例.md` が見本）。見出しは省かない。

```
## 作業
（番号と名前）

## 状態
完了 / 進行中 / 止まっている

## やったこと
（3行以内）

## 確かめたこと
（実行したテストと結果、見た画面）

## 確かめ役の指摘
高 x 件 / 中 y 件 / 低 z 件（対応済み・未対応）

## 残っていること
（残っていること・心配なこと）

## 持ち主に決めてほしいこと
（なければ「なし」）

## 画面で確かめる手順
（3〜5行）
```

「完了」は作り手が決めない。持ち主が画面で確かめて決める。
見出しがそろっているかは、人が見る前に機械が確かめる（`05_機械で確かめる.md`）。
