# 指摘をルールにする

人や確かめ役が同じ指摘を何度もしているなら、それは機械に任せられる。
人に届く件数を減らし続けるための、改善の手順。

## 手順

1. 報告やレビューで出た指摘の理由を、`指摘の記録.md` に1行ずつ書く（日付・理由・直したか）
2. 同じ理由が2回出たら、ルールの候補にする
3. 候補を、次のどれで書けるか考える
   - 見出しや項目の有無、決まった言葉の有無、数字の一致 → 機械の検査（`報告/chaff.yaml`。`required_sections`、`jargon`、`prefer`、`custom_rules`）
   - 書けない（中身が妥当か、説得力があるか） → AI への指示書（`CLAUDE.md`）に足す
4. 新しい検査は、まず警告で入れる。今ある報告の違反をゼロにしてから、エラーに上げる
   （`npx -y chaffjs relax ルール名 --why "理由"` や `strict` で段階を変える。理由と日付が残る）

## 守ること

- ルールを足すときは、そのルールを破った短い見本を作り、ちゃんと指摘されるか確かめてから入れる
- 検査を通すためだけに、ルールを緩めたり off にしたりしない
- 品質は、送ったあとの差し戻し・訂正・事故の件数で見る。介入を減らして増えたら、一段戻す

## 指摘の記録（書式）

```
2026-10-13 | 報告に「画面で確かめる手順」がない | 直した
```
