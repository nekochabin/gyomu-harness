# 機械で確かめる

AI が「できました」と言っても、報告の形が崩れていることがあります。
ここは AI の判断ではなく、文章の検査ツール chaff で、毎回同じ基準で確かめます。
同じ文章なら何度かけても同じ結果になり、文章は書き換えません。
chaff の場所： https://github.com/isamu/lab/tree/main/text/packages/chaff

## 何を確かめるか

- 報告に、決めた見出しがすべてあるか（`報告/chaff.yaml` の `required_sections`）
- 言い回しの読みにくさ（一文の長さ、表記のゆれなど）

## 使い方

1. 作りたいツールのフォルダに、`harness/報告/` を丸ごとコピーする
2. AI は報告を `報告/報告_日付.md` に書く
3. AI は書いたあとに次を実行する

```
cd 報告
npx -y chaffjs 報告_日付.md
```

4. 結果の見方
   - 「見出しがありません」（error）が出たら、AI は直してからやり直す。直らないままなら `03_止まる条件.md` の「同じ失敗を2回繰り返した」に当たるので、止まって報告する
   - 注意（warning）と参考（info）は、持ち主に見せる報告の「残っていること」に書いてよい

## AI に手順を覚えさせる（skill）

`skills/chaff/SKILL.md` に、chaff の使い方を AI 向けにまとめてある（有本さんの同梱 skill を、このハーネス向けに移したもの）。
作りたいツールのフォルダの `.claude/skills/chaff/SKILL.md` にコピーすると、Claude Code が報告を書いたあとに自分で使う。
原本をそのまま入れたいときは、そのフォルダで `npx -y chaffjs skill` を実行する。

## 見出しを変えたいとき

`報告/chaff.yaml` の `required_sections` の一覧を直す。`04_報告の型.md` も同じ見出しにそろえる。

## 限界

- 見出しがあるかは確かめられるが、中身が正しいかは確かめられない。中身は「確かめ役」と持ち主が見る
- `cd 報告` が必要なのは、設定ファイル（chaff.yaml）をそのフォルダから読むため
