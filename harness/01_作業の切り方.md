# 作業の切り方

1つの作業は「半日以内で終わり、1つの合格条件で判定できる大きさ」にする。
大きすぎると、AI はそれらしく全部作り、どこが違うのか人が確かめられなくなる。

## 型

```
番号：
目的：（何ができるようになるか、1行）
触ってよい範囲：（ファイルや画面）
触ってはいけない範囲：
合格条件：（画面で見て分かる事実、またはテストの結果）
```

## 例

```
番号：3
目的：研修の申込者一覧に「出席」のチェックを付けられるようにする
触ってよい範囲：出欠画面、出欠のデータ
触ってはいけない範囲：申込フォーム、アンケート
合格条件：チェックを付けて再読み込みしても残っている。別の研修の一覧には影響しない
```

## よくある失敗
- 「いい感じにして」→ 合格条件が無いので、終わりが決まらない
- 「申込から集計まで全部」→ 大きすぎる。3〜5個に分ける
