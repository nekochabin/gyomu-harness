# 業務を言葉にする（記入例：研修の申込・出欠・アンケート）

## 1. 何のための仕事か
- 困る人：研修の主催者（人事・講師）。参加者の把握と、終わった後の報告ができない
- 「できた」：申込者・出席者・アンケート結果が1か所で見られ、報告書に貼れる

## 2. 誰が、どこで困っているか
- 関わる人：主催者、講師、参加者
- 時間がかかる作業：申込フォーム・紙の出席簿・アンケートを手で突き合わせる
- よく起きる間違い：当日参加・欠席の反映漏れ、アンケートの数え間違い

## 3. 今の流れ
1. フォームで申込を受ける
2. 当日、紙やスプレッドシートで出欠を取る
3. アンケートを別のフォームで取る
4. 3つを手で合わせて、出席率と満足度を報告する

## 4. どこを人が確かめるべきか
- 取り返しがつかない：出席の記録（助成金や修了証の根拠になる）
- AI に任せてよい：集計、グラフ、報告文の下書き

## 5. 扱うデータ
- 個人情報：氏名、所属、メール
- 外に出さない：参加者の個人情報、アンケートの自由記述（デモはすべてダミー）

## 6. 最初に作る最小のもの
- 研修を1つ登録し、申込者一覧に出席チェックを付けられる
- 合格条件：チェックを付けて再読み込みしても残る。別の研修には影響しない

## 作業の予定（01 の型で切る）
1. 研修の登録と一覧
2. 申込の受付（公開フォーム）
3. 出席チェック
4. アンケートの受付
5. 出席率・満足度の集計と、報告用の表の出力
